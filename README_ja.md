# ネジ計数トレー — Revision 4

1列ごとの軽いクリック停止を追加。穴の行列数・M1.5/M2/M3の設定化、本体上下分割、磁石式の蓋、角の丸みも維持しています。
添付した印刷モデルはM2・4行×10列。まず4行×2列の試験版で摺動・保持・落下・磁石の嵌合を確認してください。前版との部品互換性はありません。

## ファイル

- `generated/ScrewCounter_M2_4x10.step`：全4部品の組立位置STEP。
- `generated/*_base.stl`：下側の開放レール。
- `generated/*_tray.stl`：穴付き板と上側周囲壁を一体にした上部トレー。
- `generated/*_slider.stl`：引き抜く板。
- `generated/*_lid.stl`：磁石式の蓋。
- `test/`：4行×2列の試験版。同じ磁石・接合部寸法。
- `design_screw_counter.py`：設定・生成・CAD検証を含むプログラム。
- `*_dimensions.json`：生成した設定・寸法・検証結果。
- `validation_matrix.json`：異なるネジサイズと行列数での検証記録。

STEPは使用時の位置関係、STLは各部品を印刷面へ平置きした姿勢です。

## 簡単な設定

プログラム冒頭近くの次の行を変更します。

```python
SETTINGS = Settings(rows=4, columns=10, screw='M2', joint='screws')
```

- `rows`：引く方向と直交する穴数。1回に落とすネジ本数。
- `columns`：引く方向の穴数。取り出せる回数。
- `screw`：`'M1.5'`、`'M2'`、`'M3'`。
- `joint`：`'screws'` は本体接合用M2×8を4本使用。`'glue'` はネジ穴を省いた接着用形状。

対象ネジをM3にしても、本体を組み立てるネジはM2のままです。

コマンドラインからも変更できます。

```bash
python -m pip install 'cadquery>=2.6,<3'
python design_screw_counter.py --rows 4 --columns 10 --screw M2 --out generated
python design_screw_counter.py --rows 6 --columns 8 --screw M3 --joint glue --out custom_M3
python design_screw_counter.py --rows 4 --columns 2 --screw M1.5 --out test_M1p5
```

設計の自動検証後、STEPと4つのSTL、寸法JSONを出力します。穴数が多いと生成・検証に時間がかかります。同じ出力先で同じサイズ名を生成すると、以前の同名ファイルを更新します。

### ネジのプリセット

単位mm。以下の頭径は設計上の想定であり、ねじ規格の保証値ではありません。なべ・キャップ・低頭など頭の形式で寸法が変わります。

|設定|軸径|想定最大頭径|長溝幅|本体穴径|板の落下窓|穴ピッチ／1回の引き量|
|---|---:|---:|---:|---:|---:|---:|
|M1.5|1.5|3.0|2.1|4.2|4.6角、角R0.65|8|
|M2|2.0|4.4|2.6|5.6|6.0角、角R0.65|8|
|M3|3.0|6.0|3.6|7.2|7.6角、角R0.65|10|

頭は長溝にかかって支えられます。実物の頭径が小さい場合は溝幅も合わせて変更してください。皿頭や極端な薄頭は別途調整が必要です。頭の高さはプリセット化していません。

実測寸法を上書きする例：

```bash
python design_screw_counter.py --screw M2 --head-diameter 3.8 --slot-width 2.5 --out custom
```

`Settings`では`shaft_diameter`、`head_diameter`、`slot_width`、`pitch`、摺動隙間も上書きできます。頭径に応じて本体穴・落下窓・最小ピッチ・外形を自動計算します。成立しない溝幅やピッチはエラーにします。

## 本体分割と固定

下部レールは上が開いたU字形で、上部トレーを載せると板を挟む案内になります。レールの長い天井を印刷しない構造です。位置決めは下部の凸4箇所と上部下面の凹4箇所で行います。

- 凸：直径4、突出1.2、先端に導入面。
- 凹：直径4.4、深さ1.45。片側0.2の隙間。
- ネジ固定：下からM2×8を4本。頭径4.2以下、頭高さ2.2以下の平らな座面のネジを想定。座ぐり径4.6、深さ2.2、軸通し穴2.4、上部の下穴1.7。印刷樹脂へねじ込む構造で、インサートは不要です。必要に応じて下穴をさらい、割れないよう手で締めてください。
- 接着固定：位置決めして合わせ面を接着。摺動部へ接着剤を流さないでください。接着用設定では固定ネジ穴を作りません。配布したSTLはネジ固定版ですが、これを接着固定することもできます。

本体サイズは標準M2・4×10で108.3×55×14。蓋を閉じた高さは17.4。取っ手は本体から19突出します。

## 磁石式の蓋

標準は直径6×厚さ2の丸型ネオジム磁石を、本体に4個、蓋に4個、合計8個使用します。

- ポケット径6.3、深さ2.15。圧入ではなく接着固定を想定。
- 向き合う磁石が引き合う極性を確認してから接着します。
- 蓋の内側に横ずれ防止のリブ、前側に指を掛けるつまみを追加。
- 磁石寸法は`magnet_diameter`と`magnet_thickness`で変更可能。対応入力範囲は直径3〜8、厚さ1〜3。寸法に応じて壁幅・磁石位置も変化します。

```bash
python design_screw_counter.py --magnet-diameter 5 --magnet-thickness 2 --out magnet5
```

蓋は上面を覆うためのものです。クリックによる軽い位置保持はありますが、抜け止め・輸送用ロックは備えていません。蓋を付けても板を引くと下へ排出します。

## 丸み

本体・蓋の外周角R4、上側の周囲壁の内側角R3、上縁R0.65、蓋上縁R0.6、取っ手外角R3、落下窓角R0.65。長溝の終端も丸めています。位置決めや摺動に必要な合わせ面は平らに保っています。

## 印刷

4部品ともSTLの向きのまま平置きし、サポートOFFを想定しています。

|部品|下にする面|特徴|
|---|---|---|
|base|凸のない底面|開放レール。位置決め凸が上|
|tray|平らな下面|周囲壁・磁石穴が上|
|slider|目盛りのない面|目盛りが上|
|lid|外側の平らな天面|裏側の磁石穴・位置決めリブが上|

本体側の凹やネジ座ぐりの小さい天井には、約4.4〜4.6 mmの短いブリッジがあります。長いレールやトレー全面のブリッジはありません。サポートを使わず印刷できる設計ですが、実機でのブリッジ品質は試験版で確認してください。

開始条件：0.4 mmノズル、積層0.16〜0.20、外周3〜4周。厚さ2 mmの板は十分な上下面層数などで実質ソリッドにします。長溝と摺動面のバリ・糸引きを除去してください。標準の摺動隙間は左右・上下それぞれ0.3。初層の広がりが大きい場合はスライサーで補正します。

## 組み立て・操作

1. 磁石を仮合わせし、極性を確認して本体・蓋へ接着。
2. 下部レールに板を置き、上部トレーを凸凹に合わせて載せます。
3. 本体をネジまたは接着剤で固定。接着剤を使う場合は硬化前後に板の摺動を確認。
4. 板を奥に戻し、各穴に軸を下向きにして1本ずつ入れます。余分なネジを取り除きます。
5. 本体の下全体を袋や受け皿で覆い、次のクリックまで引き、目盛り1で手を止めます。4本の落下を確認して袋を交換します。
6. 目盛り2、3…へ進めます。M2標準なら8 mm刻み、M3標準なら10 mm刻み。
7. 全部空になってから板を戻します。

目盛りは排出した列数です。1列ごとに軽いクリックがあります。強く引き続ければ乗り越えるため、クリックごとに手を止め、排出を確認してください。排出位置は列ごとに移るため、小さい袋口へ1箇所に集める場合は別途漏斗が必要です。

## 検証範囲

- 標準M2・4×10と試験M2・4×2：4部品が有効な単一ソリッド、組立時の部品間干渉なし。
- 各停止位置でレール・トレーと板の干渉、対象の頭が落下する経路、残りの頭の保持、軸の通過を確認。
- M1.5・3×3・接着版、M3・6×3・ネジ版、M2・1×1・ネジ版でも同じCAD検証を実施。
- 磁石の想定形状とポケットの干渉、磁石位置と本体固定部の離隔を確認。
- 実際の造形、剛性、摩擦、磁石保持力、接着強度、ねじ込み強度、ネジの傾きや連続排出は未検証。


## Revision 4：弱いクリック停止

引き抜き板の目盛りと反対側に一体造形の片持ち板ばねと丸い爪を追加しました。下部レールには初期位置0と各排出位置1〜列数に浅い円弧状のくぼみがあります。M2とM1.5標準は8 mm、M3標準は10 mm間隔です。

爪はくぼみの中でほぼ無負荷になり、引くと内側へたわんで次のくぼみに入ります。停止位置で頭を通す落下窓が対象列に一致します。戻す方向でも乗り越えられる対称形です。ばね・爪は板に一体で、追加の金属部品はありません。

- ばね有効長：約15 mm。
- ばね幅：標準1.2 mm、板厚2 mm。
- 爪半径1 mm、くぼみ半径1.2 mm。
- 標準位置での最大たわみ約0.5 mm、横の遊びを含む設計上の最大移動0.8 mm。内側に1.2 mmの逃げ。
- 標準M2・4×10版は初期位置を含め11箇所で軽く止まります。
- ばね周囲の肉厚を確保するため、前版から本体幅を53→55 mmに変更しました。上部トレーと蓋も含め、この版の一式で使ってください。

クリックの強さは材料、積層、印刷誤差で変わります。具体的な操作力や寿命は実測していません。まず4×2試験版で試し、弱ければばね幅を増やし、強ければ減らして再生成します。

```python
SETTINGS = Settings(rows=4, columns=10, screw='M2',
                    detent=True, detent_spring_width=1.2)
```

```bash
# より弱いクリック（ばね幅1.0 mm）
python design_screw_counter.py --columns 2 --detent-spring-width 1.0 --out light_test
# やや強いクリック（ばね幅1.4 mm）
python design_screw_counter.py --columns 2 --detent-spring-width 1.4 --out firm_test
# クリックなし
python design_screw_counter.py --no-detent --out no_detent
```

ばね幅の入力範囲は1.0〜1.5 mmです。変更に応じて周囲の余裕も再計算するため、寸法JSONを確認し、その設定で生成した部品一式を組み合わせます。スリットの糸引きや初層のつながりを取り除き、爪が内側へ軽くしなることを確認してから組み立ててください。

これは弱い位置決めであり、各列で絶対に止まるラッチではありません。勢いよく引けば複数列を通過します。必ず4本だけに制限する運用には、別途解除操作を要するラッチが必要です。

### 追加のCAD確認

各クリック位置と排出位置の一致、停止時の爪とくぼみの隙間、各列での保持・落下、列間では接触がしなる爪に限られること、爪を内側へ0.8 mm移動した形状がレールを逃げることを確認しています。ばね全体の大変形・応力解析や実機試験は行っていません。
