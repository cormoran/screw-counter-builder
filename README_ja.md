# ねじカウンター生成器

> English: [README.md](README.md)

決まった本数ずつネジを取り出すための、3Dプリント用トレーをブラウザで生成するツールです。ネジとバッチの寸法を設定し、モデルを確認してから、設計データをサーバーへ送らずに生成できます。

[ねじカウンター生成器を開く](https://cormoran.github.io/screw-counter-builder/)

## 生成できるファイル

- ベース、トレー、スライダー、ふた、漏斗の印刷向きSTL。
- 組立位置のSTEP。
- CADファイル、寸法、検証結果をまとめたZIP。
- 5部品を選択した印刷プレートへ配置したBambu Studio用3MF。

生成器はブラウザ内でReplicadとOpenCascade WebAssemblyを使って動作します。CADエンジンと生成したモデルは端末内に留まり、サーバーへ送信されません。

## Webアプリの使い方

1. 対象のネジ、1回に出す本数、取り出し回数を選びます。
2. 2Dまたは3Dのライブプレビューを確認します。詳細設定では、実測したネジ・磁石・クリアランスの寸法を入力できます。
3. **モデルを生成**を選ぶと、完全なCAD生成を実行してSTL、STEP、ZIPをダウンロードできます。
4. Bambu Studio用には対応するプレートサイズを選び、3MFを生成してから、Bambu Studioでプリンター、材料、印刷条件を選んでスライスします。

アプリの表示は英語と日本語に対応しています。アプリで明示的に言語を選ぶまではブラウザの言語設定を使い、選択後は次回以降もその言語を保存します。

## 印刷と組み立て

出力はベース、トレー、スライダー、ふた、漏斗の5部品です。各STLは出力時の向きで印刷してください。組み立て時は、スライダーをベースへ上から載せてからトレーを固定します。標準のねじ留めではM2 × 5を4本使います。ふたの位置合わせには磁石または印刷した凹凸を選べます。

プリセット寸法は設計の出発点であり、ねじ規格を保証するものではありません。実物のネジを測り、小さな試験造形で嵌合、スライダー、クリック停止、磁石の保持、強度を確認してから本番で使用してください。

## ローカル開発

Node.jsとnpmが必要です。

```sh
cd web
npm ci
npm test
npm run build
```

ローカル開発サーバーは`npm run dev`で起動します。既定のCAD形状を変更した場合は、コミット前に事前生成プレビューを更新してください。

```sh
npm run generate:default-preview
```

## リポジトリ構成

- `.github/workflows/web.yml` — テスト、ビルド、GitHub Pages配信のワークフローです。

## 検証範囲

自動テストでは設定、CAD生成、エクスポート、プレビュー動作、印刷プレート配置を確認します。出力したCADファイルは使用するスライサーまたはCADツールで開いて確認してください。実際の印刷、嵌合、耐久性、排出動作は、使用するプリンターと部品での検証が必要です。

### 漏斗と切り欠き用のふた

取り外し式の漏斗は高さ14 mmの箱形で、内部の傾斜でタブと反対側に寄せた角丸正方形（R2）の出口へネジを集めます。出口幅は5〜24 mm（既定10 mm）です。ベースの四隅のねじ留め位置に磁石（4組・計8個）または割り入りの爪を埋め込み、外周から張り出さず固定します。穴の中心は既定で外壁から4.5 mm（従来より1 mm外側）で、磁石穴と直線部の外壁の間を1.35 mm以上確保します。漏斗は外周四隅をR4、外周の上下の縁をR0.6、内部と固定座の角をR2、入口と出口の縁をR0.4に丸めます。ベース裏面は平らで、印刷する固定部の突起はありません。磁石穴の深さは最大1.5 mmとし、磁石の突出分を漏斗側で受けます（既定の厚さ2 mmの磁石とクリアランスでは0.65 mm突出）。ねじ頭の座ぐりとトレー側の下穴も内側へ深くし、磁石との重なりを避けます。組立ねじを先に取り付けてから磁石を入れてください。ねじ留め時の磁石・凹凸径は5 mm以上です（接着時は3 mmから使用可能）。漏斗は出口を下に印刷し、四隅の固定部の下のサポートをスライサーで確認してください。低くしたため傾斜45度以上の保証はありません。ネジの流れ、磁石と爪の保持力は実物で確認が必要です。固定穴の位置が変わるため、ベース・トレー・ふた・漏斗を更新版で揃えてください。

詳細設定 → 収納・操作から、全面用／切り欠き用のふたを選べます。切り欠き用は枠の排出口と上面手前の細い帯だけを覆い、磁石2個（トレー側と合わせて4個）または凹凸2か所で取り付けます。残りの上面は開放されます。磁石寸法はふたと漏斗で共通です。既存の設定ファイルも読み込めます。

### トレーの形状とねじの長さ

基本設定で「ねじの長さ」（初期値5 mm）と「トレーの形状」を指定します。「自動」では5 mm以下は正方形の穴、5 mm超はくり抜きになります。長さに関係なく、どちらかの形状を手動指定することもできます。正方形穴のトレーは、個別の角穴と入口の0.3 mm面取りを復元します（既定M2ではストレート部分が3.5 mm角）。ベースはどちらも現在の正方形の穴を使います。収納スペースの高さは別設定です。

長さと形状は設定ファイルに保存され、再読み込み後も復元されます。項目のない旧ファイルは5 mm・自動として読み込みます。プレビューと出力は自動選択後の形状を使い、形状切り替えで変わるのはトレーだけです。

リアルタイムプレビューとモデル生成では、ベース → スライダー → トレー → 漏斗 → ふたの順に、完成した部品から表示します。残りの部品を生成している間も、表示済みの部品を確認できます。部品が増えてもカメラの表示範囲は一定に保ち、ダウンロード用ファイルは全体の生成・検証が終わってから利用できます。
