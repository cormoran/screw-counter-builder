# ねじカウンター生成器

> English: [README.md](README.md)

決まった本数ずつネジを取り出すための、3Dプリント用トレーをブラウザで生成するツールです。ネジとバッチの寸法を設定し、モデルを確認してから、設計データをサーバーへ送らずに生成できます。

[ねじカウンター生成器を開く](https://cormoran.github.io/screw-counter-builder/)

## 生成できるファイル

- ベース、トレー、スライダー、ふたの印刷向きSTL。
- 組立位置のSTEP。
- CADファイル、寸法、検証結果をまとめたZIP。
- 4部品を選択した印刷プレートへ配置したBambu Studio用3MF。

生成器はブラウザ内でReplicadとOpenCascade WebAssemblyを使って動作します。CADエンジンと生成したモデルは端末内に留まり、サーバーへ送信されません。

## Webアプリの使い方

1. 対象のネジ、1回に出す本数、取り出し回数を選びます。
2. 2Dまたは3Dのライブプレビューを確認します。詳細設定では、実測したネジ・磁石・クリアランスの寸法を入力できます。
3. **モデルを生成**を選ぶと、完全なCAD生成を実行してSTL、STEP、ZIPをダウンロードできます。
4. Bambu Studio用には対応するプレートサイズを選び、3MFを生成してから、Bambu Studioでプリンター、材料、印刷条件を選んでスライスします。

アプリの表示は英語と日本語に対応しています。アプリで明示的に言語を選ぶまではブラウザの言語設定を使い、選択後は次回以降もその言語を保存します。

## 印刷と組み立て

出力はベース、トレー、スライダー、ふたの4部品です。各STLは出力時の向きで印刷してください。組み立て時は、スライダーをベースへ上から載せてからトレーを固定します。標準のねじ留めではM2 × 5を4本使います。ふたの位置合わせには磁石または印刷した凹凸を選べます。

プリセット寸法は設計の出発点であり、ねじ規格を保証するものではありません。実物のネジを測り、小さな試験造形で嵌合、スライダー、クリック停止、磁石の保持、強度を確認してから本番で使用してください。

## ローカル開発

Node.jsとnpmが必要です。

```sh
cd web
npm ci
npm test
npm run build
```

ローカル開発サーバーは`npm run dev`で起動します。既定のCAD形状を変更した場合は、コミット前に事前生成プレビューを更新してください。

```sh
npm run generate:default-preview
```

## リポジトリ構成

- `web/` — Vite、React、TypeScriptによるアプリケーション。ブラウザ内CAD生成とテストを含みます。
- `.github/workflows/web.yml` — テスト、ビルド、GitHub Pages配信のワークフローです。

## 検証範囲

自動テストでは設定、CAD生成、エクスポート、プレビュー動作、印刷プレート配置を確認します。出力したCADファイルは使用するスライサーまたはCADツールで開いて確認してください。実際の印刷、嵌合、耐久性、排出動作は、使用するプリンターと部品での検証が必要です。
